## Already jailbroken consoles

After you press Start, the page checks whether the browser can gain root privileges. If the kernel jailbreak is already active, it skips the kernel exploit and does not relaunch the payload. The initial browser exploit is still needed for this check.

To explicitly relaunch the payload on an already jailbroken console, add `?relaunch=1` to the page URL.
